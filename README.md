# טופס טלפוני לאומדן חיסכון ממיחזור משכנתא

שרת Node.js ללא תלויות חיצוניות, המיועד ל־Module API של טכנוליין.
המרכזייה שולחת GET לכתובת השרת; התשובה היא מודול JSON אחד בכל שלב.
הפרויקט אינו משתמש בסטרימינג, במפתח AI או ב־Interaction API.

## השיחה

1. לפני כמה שנים נלקחה המשכנתא? מספר שנים שלמות, 0–40.
2. לכמה שנים נלקחה במקור? 1–40, ולפחות מספר השנים שכבר חלפו.
3. סכום המשכנתא המקורי בשקלים: 1–99,999,999, ספרות בלבד.
4. השמעת השנים שנותרו ואומדן החיסכון; בקריאה הבאה מוחזר hangup.

מסיימים הקשה בסולמית. מתחת לשנה מקישים 0.
תשובות מספריות נקלטות דרך getDTMF ושמות השדות הם
mr_elapsed, mr_term, mr_amount.
יש אימות קלט, ניקוי תשובות המשך לאחר שגיאה, וסיום לאחר שלוש תשובות שגויות מצטברות.
התנהגות סולמית, חוסר מענה והודעות מערכת תלויה גם בהגדרות מודול המרכזייה.

## הנוסחה שהוגדרה

שנים שנותרו = תקופה מקורית פחות שנים שחלפו.

אומדן חיסכון בשקלים = סכום מקורי × שנים שנותרו ÷ 50, מעוגל לשקל הקרוב.

דוגמאות:

| סכום מקורי | תקופה מקורית | שנים שחלפו | נותרו | אומדן |
|---|---|---|---|---|
| 100,000 | 25 | 5 | 20 | 40,000 |
| 500,000 | 25 | 5 | 20 | 200,000 |
| 100,000 | 20 | 10 | 10 | 20,000 |

זה מודל יחסי שהוגדר על ידי בעל המערכת. הסכום המקורי אינו יתרת הקרן.
אין כאן חישוב סילוקין, ריבית, הצמדה או עמלות, ולכן המערכת משמיעה במפורש שמדובר באומדן.
כאשר התקופה הסתיימה מושמע אפס.

## פיתוח ובדיקות

נדרשת Node.js 22 ומעלה.

```sh
npm ci
npm test
npm start
```

בדיקת פתיחה: http://localhost:3000/ivr
בדיקת תוצאה: http://localhost:3000/ivr?mr_elapsed=5&mr_term=25&mr_amount=100000
בדיקת סיום: http://localhost:3000/ivr?mr_stage=done

## פריסה ב־Render

המאגר מכיל render.yaml. יוצרים Blueprint מהמאגר והענף main.
ההגדרה יוצרת Web Service, מריצה בדיקות בבנייה, ומגדירה סוד URL אוטומטי.
לאחר הפריסה לוקחים את כתובת השירות ואת IVR_PATH_SECRET ממסך Environment.

הכתובת להגדרה בטכנוליין:

```text
https://<your-service>.onrender.com/ivr/<IVR_PATH_SECRET>
```

אין לפרסם את הסוד או את הכתובת המלאה. אין צורך ב־apiKey או בכותרת Authorization.
בפרודקשן השרת מסרב לעלות בלי סוד של לפחות 24 תווים בטוחים ל־URL.
בדיקת בריאות: /healthz.

ה־Blueprint מוגדר למסלול free כדי לא ליצור חיוב אוטומטי.
שירות חינמי עשוי להירדם; לפני שימוש בקו פעיל יש לבחור שירות שאינו נרדם ולבדוק זמני תגובה.
בחירת מסלול בתשלום נעשית בחשבון Render.

## הגדרה בטכנוליין

1. בשלוחת ה־IVR בוחרים מודול URL/API המפנה לכתובת השרת לעיל.
2. מגדירים paramsMode לערך chain, כדי שכל תשובה תישלח גם בקריאות הבאות.
3. מאפשרים טקסט לדיבור בעברית בקובצי files עם text וקריאת number למספרים.
4. מוודאים שאין פרמטרים קבועים ששמותיהם מתחילים ב־mr_.
5. מבצעים שיחת ניסיון: 5, 25, 100000; התוצאה הצפויה 40,000 שקלים.
6. בודקים גם אפס שנים שחלפו, תקופה שנסתיימה, קלט שגוי, ושתי שיחות במקביל.

היישום נשען על המסמך PBX_DOCUMENTATION_CENTER.md שסופק:
getDTMF עם name, files, min, max, timeout;
simpleMessage עם files; hangup; addParams ו־removeParams.
הוראות מפורטות: https://pbx.tlivr.com/apiModuleDocs.html
מרכז התיעוד: https://pbx.tlivr.com/pbxDocsCenter.html

אין תלות בזיכרון שרת: מצב השיחה נמצא בפרמטרים שמרכזיית טכנוליין צוברת.
לאחר הגדרת החיבור, טפסים שהושלמו נשלחים לגוגל שיטס הפרטי שלך. אין מסד נתונים בשרת ואין רישום כתובות הבקשות בלוג היישום. ההגדרה ב־[GOOGLE-SHEETS.md](GOOGLE-SHEETS.md).
יש לשמור על פרטיות גם בהגדרות הלוגים של ספק האירוח ושל המרכזייה.
